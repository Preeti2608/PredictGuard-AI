Casting Model Specifications

  • Model Filecasting_defect_classifier.h5
  • ArchitectureConvolutional Neural Network (CNN)
  • FrameworkTensorFlow 2.20 / Keras 3
  • Input Resolution224 × 224 × 3 (RGB)
  • NormalizationArray / 255.0 ([0.0, 1.0])
  • Output ActivationSigmoid activation (score in [0, 1])
  • Threshold0.50 (score ≥ 0.50 → ok_front)
  • Class Mapping0: def_front, 1: ok_front

Sensor Pipeline Specifications

  • Model Filedecision_tree.joblib
  • ArchitectureScikit-Learn Pipeline
  • PreprocessorColumnTransformer
  • Numerical TransformStandardScaler (5 features)
  • Categorical TransformOneHotEncoder (Type: L, M)
  • ClassifierDecisionTreeClassifier (101 nodes)
  • Class 0No Failure (Normal state)
  • Class 1Failure (Maintenance state)
